# 红源智导 · 革命老区 AI 导览智能体（v1.3）

> 参赛命题：**AI 赋能革命老区振兴**
> 作品形态：可运行的 Web 智能体 + 20 页参赛作品说明（PDF）+ 答辩 PPT（16:9）
> 服务区域：陕西省延安市（红色文旅 + 地理标志农产品）

---

## 一、这是什么

红源智导是一个面向革命老区延安的「红色文旅 + 农产品 IP」一体化导览智能体。它只做四件事：

| 模块 | 能力 | 关键约束 |
|---|---|---|
| 讲解 | 18 个点位的历史与看点 | 38 条事实，逐条标注机构 / 文件 / 日期 |
| 行程 | 1–4 天、5 类主题的路线 | 只编排知识库内已核验点位，不虚构景点 |
| 农品 | 10 个地标产品的产地事实与推广文案 | 事实槽位填充 + 广告法违禁词检查 |
| 边界 | 天气 / 余票 / 未收录实体 | 不猜，直接说明并给官方入口 |

作品的核心主张：**在革命老区做 AI，可信度比覆盖面更重要。**

## 三、如何运行

```bash
cd hongyuan-zhidao
python run.py --port 8770
# 浏览器打开 http://127.0.0.1:8770
```

要求：Python 3.12（仅标准库，无需 pip install）；Windows / macOS / Linux 均可。
首次运行前如缺少账号文件，执行：

```bash
python tools/make_users.py
```

复跑评测与重建文档：

```bash
python eval/run_eval.py          # 46 条评测，输出 eval/results.json
python tools/build_pdf.py        # 重建 20 页 PDF
python tools/build_pptx.py       # 重建 18 页答辩 PPT
```

## 四、接入 DeepSeek API（可选：联网实时生成）

默认**不联网、不调用任何外部 API**，评审在断网环境也能完整体验。
若需要更自然的表达与实时信息，填入 DeepSeek API Key 即自动切换：

`powershell
=sk-...
python run.py --port 8770
# 或写入 data/config.json（参考 data/config.example.json）
`

启用后（两个官方接口，共用一个 key）：

| 能力 | 接口 | 行为 |
|---|---|---|
| 生成 | POST /chat/completions（deepseek-flash） | 基于知识库重写答案，必须带 [S1] 引用；出现资料外的大数字会被判定为幻觉并回退 |
| 联网 | POST /v1/tools/search | 遇到“最新/今天/开通/天气”等时效问题才触发；结果带站点与日期，标注“未人工复核” |
| 边界 | —— | 门票、开放时间等结构化字段**仍走本地官方表**，不让模型改写数字 |

任何超时 / 401 / 402 / 5xx 都会自动回退到本地规则，页面显示“接口异常，已回退”。
关闭：REDORIGIN_LLM=0、REDORIGIN_SEARCH=0，或删掉 key。
计费参考：Search 5 元 / 1000 次，对话按 token 计费（以官方价格页为准）。

> 说明：DeepSeek 开放平台只提供 API 与用量管理，没有第三方智能体托管入口，
> 因此**无法把作品发布到 deepseek.com 的固定网址下**；固定域名需自建托管（见 deploy/README_部署.md）。

## 六、数据与真实性

所有事实均来自公开、可打开原文的来源，主要渠道：

1. **政府统计**：延安市人民政府《2024 年延安市国民经济和社会发展统计公报》（2025-05-30）
2. **主管部门**：延安市文化和旅游局《延安市 A 级旅游景区基本信息表》（2026-10-26）
3. **政策原文**：中国政府网（国发〔2021〕3号、国发〔2025〕11号、中办国办 2026-03-13 意见、文旅部办资源发〔2024〕82号）
4. **权威媒体与政府发布**：新华社、陕西日报、陕西省人民政府、洛川县人民政府

处置原则：

- 未核实的数据不进知识库（如梁家河未列入 A 级景区名录，故不报价、不排线）；
- 来源冲突的数据单列说明，不合并、不平均（如延安革命纪念馆馆藏量两种口径）；
- **品牌价值 ≠ 产值**：洛川苹果品牌价值 883.26 亿元、县域产值 140 亿元，作品严格区分；
- 不接入、不推测天气 / 客流 / 余票 / 库存。

## 九、安全与隐私

- 密码以 PBKDF2-SHA256（120000 轮、随机盐）存储，不存明文；
- 登录接口限流（12 次 / 分钟 / IP），全局 40 次 / 分钟 / IP；
- 日志仅记录问句、意图、时延、命中来源，不含身份证 / 手机号等个人信息；
- 会话 Token 8 小时过期；服务默认仅监听本机可访问的端口，部署公网前请加 HTTPS 与网关鉴权。
